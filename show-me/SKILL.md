# show-me

長い文章は読むのに疲れる。内容を「形」にして、一目で分かるように見せ直す。

## 対象

- 引数があれば、その対象（ファイル、機能、変更内容など）を見せる
- 引数がなければ、直前の自分の応答を見せ直す

## 形の選び方

内容に合う形を1〜2個選ぶ。全部使わない。

| 見せたいもの | 形 |
|---|---|
| ファイル・ディレクトリ構成 | 浅いツリー＋各行に役割を一言 |
| 処理の流れ・呼び出し関係 | 字下げした呼び出しの連鎖（関数名 (ファイル:行)） |
| 変更点 | 上記ツリーや連鎖に `+` / `-` / `~` 印を付けた差分の形。変わらない部分は省く |
| これから作るものの設計 | 型・関数のシグネチャだけのスケッチ、または疑似コード |
| 状態の移り変わり・やりとりの順序 | 矢印の図（A → B → C）、必要ならMermaid |
| 複数案の比較 | 表（列は比較の観点、最後におすすめ） |

## 書き方のルール

- 冒頭に1行だけ要約を書き、すぐ形に入る
- 形の外の説明は3行以内
- 重要でない枝・行は省き、`...` で省略を示す
- 実在するファイル・関数を示すときは、実際に確認してから書く（推測で埋めない）
- それでも収まらない大きさなら、HTMLページにまとめることを提案する

## 例

```
ログイン処理の流れ
POST /login
└─ SessionsController#create (app/controllers/sessions_controller.rb:5)
   ├─ User.find_by(email:)
   ├─ user.authenticate(password)   ← bcrypt
   └─ session[:user_id] = user.id → redirect_to root_path
```
